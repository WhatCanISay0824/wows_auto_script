# 直营服亚服客户端配置

本目录对应脚本客户端编号 `wg_asia`。GUI 设置页可直接选择，CLI 使用 `--profile wg_asia`。请先在游戏启动器登录亚服并进入港口；脚本选择配置不会替游戏登录或切换服务器。

## 资源与适用范围

- `profile.yaml`：窗口匹配、界面模板、区域、状态和操作步骤。
- `keys.yaml`：按键映射。
- `features/`：界面图片；`marker/`：小地图己方标记。
- `ships/<ship_id>/`：船卡、选中证据、血量身份模板和船只配置。

初始资源从 `cn360` 复制，为独立普通文件。初始语言为简体中文，客户区为 2560×1600。服务器相同也可能因语言、界面缩放、版本、小地图大小不同而需要重新标定。英文和繁体中文界面不能直接假定兼容。示例船只也必须与该账号实际拥有的船相符。

2026-11-04 根据亚服会话 40 的保存截图，将小地图范围校正为 `[0.796875,0.675,1,1]`，即右下角 520 像素正方形；扣除 2 像素边框后为 516×516。己方标记颜色范围使用已有真实小地图通过原模板阈值的标定，保留原始颜色掩码回退。镜头扇区颜色和其他客户端保持各自配置。

完整小地图、己方定位、导航归一化坐标及行为切换通过已有国服真实小地图的离线回放。该样本只用于检查亚服配置的数据处理，不能替代亚服实机存活画面验证；本次亚服仅保存死亡画面，因此仍保留待标定提示。游戏内改变小地图大小后应重新标定，不能直接沿用这里的尺寸。

## 使用步骤

1. 停止托管，在游戏启动器选择亚服与简体中文，进入港口。设置与基线一致的客户区、界面缩放和小地图大小。
2. 在 GUI 设置页选择“直营服 · 亚服（简体中文）”，点击校验。初始会显示待标定警告；这不代表已通过实机识别验收。
3. 使用“界面区域标定”和“自身标记标定”，从本服务器截图核对并修正模板。命令行也可执行 `py -3.14 -m src.tools.calibrate_profile --profile wg_asia` 和 `py -3.14 -m src.tools.capture_marker --profile wg_asia`。
4. 从 GUI 导入本账号目标船的船卡，再用船只标定补齐选中证据和血量身份模板。命令示例：`py -3.14 -m src.tools.calibrate_ship --profile wg_asia --ship-id <ship_id> --display-name <船名> --screenshot <本服截图>`。
5. 执行 `py -3.14 -m src.tools.validate --profile wg_asia --ship <ship_id>`，随后用单场托管检查选船、匹配、巡航、死亡退出和正常结算。验证完成后可将本目录 `profile.yaml` 的 `calibration_required` 改为 `false`，关闭待标定提示。

本目录的图片和船只档案均独立保存，标定时不会写入 `cn360` 或其他服务器。后续国服模板更新不会自动同步到这里，需要按本服实机结果维护。
