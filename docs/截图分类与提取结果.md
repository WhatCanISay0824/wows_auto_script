- 15 张截图文件为 2559×1599，而实机窗口客户区实测 **2560×1600**，`reference_resolution` 已改为

- **实机画面与历史截图的标签栏位置有约 4% 宽度差异**：`port_indicator` / `port_equip_tab`
  已按实机 2560×1600 画面重新提取并加宽搜索区域（`port_tab` 模板不再需要，已删除）；
  其余模板（加入战斗/联合作战/信号旗/船卡等）在实机上实测得分 0.96～1.0；
- 实机预检已确认：切到装备页后 `loadout_signal_flags`（信号旗 0/8）命中 0.999，
  点回港口后 `port_indicator` 命中 1.0，铁公爵卡片命中 0.995；
- 其中 6 张实际编码是 WebP（扩展名仍是 .png），OpenCV 需 `np.fromfile + imdecode`，已按要求处理；
- 212029 右下角有“截图工具”弹窗、212021 也有系统提示，提取模板时已避开该区域；
- 模板尽量避免动态内容：`death_banner` 只取静态句子（不含玩家名/舰名）、`battle_results` 取右侧固定分页

## 3. 从截图中确认/修正的设计事实

1. **小地图在右下角**（不是设计初稿假设的右上），实测内容区归一化
   `[0.798, 0.677, 0.999, 0.994]`，已更新 `profile.yaml`。
2. **己方血条在左下**，实测整条血条区域 `[0.014, 0.737, 0.130, 0.7665]`（ISS-002 后改为
   颜色无关的填充列比例判读，绿色 HSV 仅作辅助），已更新 `profile.yaml`。
3. **设置自动驾驶必须先按 `M` 打开全屏地图再点选**（2026-10-30 实机确认，纠正此前假设）：
   全屏地图界面显示“左键点击来设置自动驾驶模式下的航向”“自动驾驶 开启”、目标线；
   直接在战斗画面右下角小地图上点击**不会**设置航向。ISS-001 已按此修复
   （`navigation.surface=full_map`，旧小地图点击仅作失败降级保留），实机回归待验证。
4. **开局可能有“未学习指挥官技能”确认框**：需要在开局序列后可选点击“是”，
   已在 `start_sequence/start_sequence_full` 增加 `battle_start_confirm_yes`（optional）。
5. **死亡提示文字**是“您的战舰已被玩家摧毁”，并提示 SHIFT 观战 / ESC 离开战斗。
6. **港口是底部船只轮播条**，没有单独的“船只列表”按钮；选船应直接在轮播条上滚轮+点卡片
   （`ship_selection_sequence` 已改为空，`card_search_region` 设为轮播条区域）；ISS-007 后
   还需用该船 `selected.png`（选中态模板）确认“已选中”，不能把“卡片可见”当作已选中。
7. **结算页胜利/失败一致**：随机战与联合作战、个人/团队分页布局相同，模板取固定分页后通用。
8. 港口截图里每艘船都有 “+50%” 经济加成标记——按你的要求保持原样、不处理。
9. **退出流程实际 UI**：ESC → 菜单（离开战斗/设置/帮助/回到战斗）→ 点“离开战斗”→ 确认框
   “离开战斗?”（是/否/继续战斗）→ 点“是”回港。模板已按此提取，状态机的“返回港口”特征
   等于菜单里的“离开战斗”按钮。ISS-002 后提前退出还必须有“血条确认归零”证据授权。
10. **装备页**：`信号旗 0/8` 表示当前未装信号旗（数量非 0 时该模板会失配 → 暂停）；左侧
    “配件和升级品”为 4 个空槽，按你的要求不读取、不点击、不修改；右侧经济加成为
    +5%/+55%/+65%/+100%，保持原样不摘除。
11. **换船**：`--ship-name 列宁格勒` → 脚本在底部轮播条滚轮查找卡片并点击，再用
    `selected.png` 确认已选中；每艘新船首次使用前需框选一次 `card.png`（船体剪影+船名，
    避开 VII/+50% 徽章与选中边框）与一次 `selected.png`（选中态卡片，含该船身份特征与
    选中高亮/边框），`calibrate_ship` 已支持两者。

**换船说明（用户：每次托管的船可能不同）**：
- `ship.yaml` 按船一份（`profiles/cn360/ships/<ship_id>/`，含 `display_name`、`card.png`，
  可选 `hp_bar.png`）；
- 启动时用 `--ship-name <船名>` 输入本次要托管的船，脚本解析到对应档案后，用鼠标滚轮在港口底部
  轮播条里找该船卡片并点击选中；`--list-ships` 可查看已有档案；
- **每艘新船首次使用前需要截一次该船的卡片**（港口轮播条里完整可见时截图），以“铁公爵”为例：
  ```powershell
  python -m src.tools.calibrate_ship --root . --ship-id iron_duke --display-name 铁公爵 --screenshot <港口截图>
  python -m src.main --ship-name 铁公爵
  ```
  之后输入船名即可自动找船。在不引入 OCR 的前提下，没有卡片模板无法识别任意船名；
- 可选：提供该船战斗画面截图裁 `ships/<id>/hp_bar.png`（ship.yaml 写 `hp_bar_template: hp_bar.png`），
  用于“血条消失”死亡信号；没有该模板时死亡判定用死亡提示/结算界面兜底。

当前船只档案：`leningrad`（列宁格勒，含 card.png + hp_bar.png）、
`iron_duke`（铁公爵，含 card.png，hp_bar 可选后补）。
