## 3. 从截图中确认/修正的设计事实

1. **小地图在右下角**（不是设计初稿假设的右上），实测内容区归一化
   `[0.798, 0.677, 0.999, 0.994]`，已更新 `profile.yaml`。
2. **己方血条在左下**，绿色填充 HSV≈(80, 208, 235)，实测区域
   `[0.026, 0.731, 0.118, 0.758]`，已更新 `profile.yaml`。
3. **小地图点击确实设置自动驾驶**：全屏地图界面显示“左键点击来设置自动驾驶模式下的航向”、
   “自动驾驶 开启”、目标虚线——V09 基本成立（仍需实机最终确认）。
4. **开局可能有“未学习指挥官技能”确认框**：需要在开局序列后可选点击“是”，
   已在 `start_sequence/start_sequence_full` 增加 `battle_start_confirm_yes`（optional）。
5. **死亡提示文字**是“您的战舰已被玩家摧毁”，并提示 SHIFT 观战 / ESC 离开战斗。
6. **港口是底部船只轮播条**，没有单独的“船只列表”按钮；选船应直接在轮播条上滚轮+点卡片
   （`ship_selection_sequence` 已改为空，`card_search_region` 设为轮播条区域）。
7. **结算页胜利/失败一致**：随机战与联合作战、个人/团队分页布局相同，模板取固定分页后通用。
8. 港口截图里每艘船都有 “+50%” 经济加成标记——按你的要求保持原样、不处理。
