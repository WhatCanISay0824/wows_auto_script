# 死亡退出交接与直营服选择修复方案

## 背景与证据

项目采用截图识别、配置化客户端和状态机驱动键鼠，GUI 与 CLI 共用运行服务。保留工作区已有修改，本次由 Codex 直接设计和实施。

`logs/session_20261102_134933.log` 显示会话完成 10 场后进入第 11 场（battle=35）。16:17:01 确认死亡，16:17:03 发送退出键，16:17:11 退出菜单超时，随即因 `recovery_mid_battle:detected=DEAD_PENDING_EXIT` 暂停。退出超时截图已经显示战斗画面上的“胜利！”，尚未进入现有模板识别的详细结算页。日志没有场次上限触发记录；数字 10 是当时完成数，并非此次暂停条件。

GUI 扫描 `profiles/*/profile.yaml`，只有一项时展示静态文字。仓库目前仅有 `cn360`，所以缺少直营服选项。

## 设计与边界

1. 保留现有识别阈值、死亡授权、会话上限和恢复频率。退出菜单超时且存在本场已授权死亡上下文时，转入被动死亡等待。优先识别正常结算，其次识别回港；期间不发送退出输入、不恢复导航和随机行为。等待期限复用 `timeouts.exit_s`，到期以 `death_result_timeout` 暂停。没有本场授权上下文仍按现有异常恢复处理。相比增加胜利文字模板，这也覆盖败北、动画和延迟；相比简单增加菜单等待时间，不会反复发送退出键。
2. 新增 `wg_asia`、`wg_eu`、`wg_na` 三套独立目录，保持现有配置格式和工具链。每套保存自己的界面、按键、标记与船只文件，便于从 GUI 独立标定。模板最初来自国服简体中文、2560×1600 基线，只证明资源可加载，不证明直营服识别有效。新增 `calibration_required` 配置字段，直营服默认开启并由校验工具提示本地标定要求。选择服务器只选择脚本配置，不代替游戏登录或切区。
3. 不引入继承机制或共享可写模板，避免标定一个客户端时影响另一个。约 0.45 MB 的初始资源复制与当前项目规模相称。不同语言和布局必须重新标定，不把国服截图当作直营服实机证据。

## 文件职责

- `src/state_machine/machine.py`：有时限的死亡后被动等待和结算衔接。
- `src/gui/viewmodel.py`：新增暂停原因的中文显示。
- `src/config/models.py`、`loader.py`、`validate.py`：读取并提示待标定状态。
- `src/gui/run_page.py`：客户端字段明确包含服务器选择。
- `profiles/wg_asia/`、`profiles/wg_eu/`、`profiles/wg_na/`：各服务器独立资源，README 说明初始来源、语言、分辨率、标定步骤。
- `tests/`：死亡交接回归、直营服加载与校验、GUI 切换和启动参数传递。

## 验收结果

1. 实现前定向回归为 9 项失败、1 项通过，复现菜单超时进入异常恢复、被动等待无法完成本场，以及直营服选项和资源缺失。
2. 最终全套 `py -3.14 -m pytest tests --basetemp pytest_work/death_wg_1102_full --tb=short --maxfail=6` 为 1202 项通过、1 项因既有本地样本缺失跳过，耗时 43.54 秒。全套覆盖本次新增的 15 项回归：死亡交接、被动等待超时与暂停恢复、兼容血条证据、场数上限、显式停止、资源加载和 GUI 选择传参。
3. `py -3.14 -m ruff check src tests`、`git diff --check` 均通过。四套客户端使用铁公爵配置校验均无错误；国服 5 条警告，直营服各 6 条，其中新增一条待本服实机标定提示，其余沿用既有配置警告。
4. `pytest_work/death_wg_1102/replay.py` 通过生产感知、状态机和真实 SessionController 回放：本次 16:17:01 死亡截图连续确认零血，发送一次 Esc；切到本次 16:17:11 胜利过渡截图后，菜单超时进入死亡被动等待，期间无动作，也不进入通用恢复；换到已有详细结算截图后点继续，再用已有排队截图接续下一场，状态机与 SessionController 完成数均从 10 增至 11，且仅增加一次。下一场建立了正常计时。
5. GUI 测试使用真实 Tk 控件，逐一选择亚服、欧服、美服，确认下拉框显示、船只刷新、传入启动服务的 profile_id 与标定上下文一致。启动服务使用替身，不启动真实游戏控制。

完整测试日志、回放脚本和结果、各客户端配置检查报告保留在 `pytest_work/death_wg_1102/`；测试临时目录为 `pytest_work/death_wg_1102_full/`。已有源码、模板与文档修改均保留。

## 使用与剩余验证

关闭旧工具并重新启动，设置页即可选择服务器。直营服首次使用前按对应 README 采集本服截图，核对简体中文、2560×1600、界面缩放和小地图尺寸，独立标定界面及目标船。校准提示不阻止配置加载，但不能据此认定识别可靠；其他语言必须重新标定。

本次没有捕获新的屏幕、切换游戏前台或发送实际键鼠。截图回放证明已有真实图像下的识别与状态衔接，不证明游戏实际接受了按键；新的真实连续托管和直营服画面验证仍未完成。过载保护、账号轮换等功能没有新的实机验收证据。
