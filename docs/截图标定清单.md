# 截图标定清单（M0 实机标定用）

> 目标：为 `profiles/cn360/` 补齐界面模板、小地图/血条区域、自身标记、船只卡片与空装备槽模板。
> 标定完成后 `python -m src.tools.validate --root .` 应从当前的 27 error 降到 0 error，
> 然后才能 `python -m src.main --dry-run` 通过并进入实机单场测试（S2）。
>
> 当前默认导航是 **autopilot**（不识别地图/不标航线），因此**不需要**外部地图底图与航线；
> 只保留 waypoints 旧模式才需要地图包。

## 0. 截图的硬性要求（不满足会导致模板匹配失败）

1. **同一台机器、同一个客户端、同一个补丁版本、同一个窗口设置**：游戏以 2560×1600 无边框窗口运行，
   UI 缩放、渲染设置、画质、HDR 等在标定后不得改动；
2. **截整窗客户区**（不含桌面/标题栏），**PNG 原图**，不要压缩成 JPG、不要缩放、不要二次裁剪，
   工具里再裁模板；
3. 鼠标指针不要压在要截的控件上；不要截悬停高亮、按钮按下、淡入淡出动画中间的帧；
4. 每个界面建议截 2～3 张（不同时刻/不同弹窗），工具里挑最稳定的一张；
5. 截图可能含其他玩家昵称，**只保存在本机**，不要公开传播；
6. **不要用网上的图片当模板**：分辨率、UI 缩放、压缩噪声、字体渲染、客户端地区/补丁差异都会让
   0.85 的匹配阈值失效。网上图片只用于“核对要截哪些界面/控件长什么样”。

截图统一放到 `screenshots/raw/`（已被 .gitignore 忽略），按下面编号命名，例如
`screenshots/raw/07_battle_hud_01.png`。

★ 07 战斗 HUD 截图同时用于：
- 标定**小地图内容区**（`profile.yaml` 的 `minimap.rect` 与 `border_px`）；
- 截取**自身舰船标记** `marker/marker.png`（autopilot 的对称敌区目标依赖它）；
- 标定**己方血条区域**与血条颜色范围（`battle_hud.hp_bar_region`、`hp_fill_hsv_*`）。

**动态界面省力办法**：排队/加载/死亡提示/弹窗这类只出现几秒的界面，可以先用
`python -m src.tools.record --root . --duration 60 --output screenshots/raw/record_flow`
录一段 2Hz 的操作流程（依次走一遍所有界面），出现 `[REC]` 后手动操作，再从
`screenshots/raw/record_flow/frames/` 里挑帧；挑选出的整帧复制成 `screenshots/raw/<编号>_<界面>_<序号>.png`
再进标定工具。

## 3. 用工具生成模板（不要手工裁剪 YAML）

```powershell
# 1) 界面模板 + 小地图/血条区域（GUI 里框选）
python -m src.tools.calibrate_profile --root . --screenshot screenshots/raw/07_battle_hud_01.png

# 2) 船只卡片 + 空装备槽
python -m src.tools.calibrate_ship --root . --screenshot screenshots/raw/03_port_ship_list_01.png

# 3) 自身舰船标记（从战斗截图的小地图区域框选，自动旋转生成模板）
python -m src.tools.capture_marker --root . --screenshot screenshots/raw/07_battle_hud_01.png

# 4) 校验（目标：0 error）
python -m src.tools.validate --root .

# 5) 只校验不运行
python -m src.main --dry-run
```

模板采集提示：模板要**包含周围固定背景**（不要把按钮内部抠得太紧）、尺寸 ≥8×8、不要纯色；
多尺度匹配只覆盖 ±5%，如果实际客户区不是 2560×1600，需要在 `FeatureDef.scales` 放宽或重截。

## 5. 标定完成后的验收顺序

1. `python -m src.tools.validate --root .` → 0 error（warning 可接受）；
2. `python -m src.tools.check_env --installed` → 窗口/截屏/DPI/输入检查通过；
3. `python -m src.tools.replay <录制目录>` 验证模板在录制画面上的识别率（可选）；
4. `python -m src.main --dry-run` → 通过后按详细设计 12.6 进入单场（S2）实机联调。
